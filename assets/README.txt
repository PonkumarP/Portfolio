ASSETS FOLDER
=============
Place the following files here:

1. profile.jpg      — Your profile photo (recommended: 400x400px, square crop)
2. resume.pdf       — Your resume/CV for the download button

Profile photo tips:
- Use a professional headshot
- Good lighting, clear background
- Square format (1:1 ratio) works best
- Minimum 300x300px, recommended 500x500px

If profile.jpg is missing, the portfolio will gracefully show a placeholder icon.
